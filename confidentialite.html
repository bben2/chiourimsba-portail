Chiourim BA — site et application

Dernière mise à jour : 25 septembre 2026

Chiourim BA est une bibliothèque d’étude gratuite : Guemara, Hassidout et Halakha en hébreu et en français. Cette page explique quelles données le site et l’application utilisent. En bref : pas de publicité, pas de pistage, pas de revente de données.

Ce qui reste sur votre appareil

Votre position de lecture, vos favoris, vos passages surlignés et vos notes sont enregistrés uniquement sur votre appareil. Nous n’y avons pas accès. Ils disparaissent si vous supprimez l’application.

Les textes

L’application télécharge les textes depuis notre dépôt public GitHub (github.com/bben2/chiourimsba-donnees) et les garde en mémoire pour la lecture hors connexion. Ce téléchargement ne transmet aucune information personnelle.

Les signalements d’erreur

Si vous signalez une erreur de traduction, nous recevons uniquement : la page concernée, le passage que vous avez sélectionné et la correction que vous proposez. Ces informations nous parviennent par e-mail ou sont enregistrées dans un espace de suivi privé (GitHub), pour être corrigées. N’y écrivez pas d’informations personnelles. Pour limiter les abus, l’adresse IP d’envoi est utilisée quelques instants pour compter les envois, puis oubliée ; elle n’est pas enregistrée.

Les questions à l’intelligence artificielle

La page « Questions à l’IA » envoie votre question à un service d’intelligence artificielle (Google Gemini) pour obtenir une réponse sourcée. N’y écrivez pas d’informations personnelles.

Ce que nous ne faisons pas

  • aucun compte n’est nécessaire ;
  • aucune publicité, aucun outil de mesure d’audience ou de pistage ;
  • aucune donnée n’est vendue ni partagée à des fins commerciales.

Contact

Pour toute question sur vos données : chiourimsba@gmail.com. Responsable : Benjamin Abbou, Chiourim BA.
